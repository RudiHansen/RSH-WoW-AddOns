# RSH WoW AddOns

A collection of personal World of Warcraft addons and related tools.

The project currently contains two small addons:

- **RSH Enable Chat Log**  
  Automatically enables WoW chat logging when a character logs in.

- **RSH Currency Tracker**  
  Tracks selected currencies and stores snapshots in SavedVariables.

The repository also contains a standalone Lua report tool for displaying the collected currency data in a readable terminal table.
